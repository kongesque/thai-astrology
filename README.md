**`thai-astrology` เป็นไลบรารีโหราศาสตร์ไทยแบบโอเพนซอร์สสำหรับ JavaScript และ TypeScript ใช้ผูกดวงตามหลักสุริยยาตร์ (Suriyayatra)** คำนวณดวงกำเนิด ราศีจักรสุริยยาตร์ ลัคนา และสมผุสดาวทั้งสิบจากวัน เวลา และสถานที่เกิด พร้อมตำแหน่งราศี องศา และลิปดา รวมถึงคำนวณดาวจรเทียบกับดวงกำเนิด

ผลคำนวณครอบคลุมภพทั้ง 12 เจ้าเรือน ตนุลัคน์ ตนุเศษ ทักษา ฤกษ์และบาทฤกษ์ รวมถึงมาตรฐานดาว พร้อมนวางค์จักร ตรียางค์จักร และปฏิทินจันทรคติไทยที่บอกวันขึ้น–แรมและเดือนจันทรคติ ข้อมูลดวงมีชื่อภาษาไทยและช่องดวงเลขไทยหรืออารบิก ใช้นำไปวาดผังดวง แสดงตารางสมผุส หรือเขียนกฎแปลผลต่อผ่าน API

เริ่มใช้งานด้วยปี พ.ศ. หรือ ค.ศ. เวลา และจังหวัดเกิด สำหรับจังหวัดไทยในช่วง ค.ศ. 1900–2100 ระบบจะเลือกพิกัด หา UTC ตามวันเวลาเกิด และคำนวณอาทิตย์ขึ้นรายวันให้อัตโนมัติ หากต้องการใช้พิกัดสถานที่เกิดจริงหรือคำนวณดวงต่างประเทศ สามารถระบุละติจูด ลองจิจูด และ UTC ที่รวมเวลาออมแสง (DST) ของวันนั้นได้

ติดตั้งผ่าน **npm** ใช้ได้กับ **Node.js 16+**, ESM และ CommonJS รวมถึงเบราว์เซอร์เมื่อใช้ bundler ไม่มี runtime dependencies และผลคำนวณแปลงเป็น JSON ได้

## คำนวณอะไรได้บ้าง

| รายการ | ผลคำนวณ | อ่านจาก |
| --- | --- | --- |
| ราศีจักร | ราศีของดาวทั้งสิบและลัคนา พร้อมช่องดวงเลขไทยหรืออารบิก | `charts.rasi` |
| สมผุสดาวและลัคนา | ราศี องศา/ลิปดา สมผุสรวม และภพของแต่ละจุด | `points` |
| นวางค์จักร / ตรียางค์จักร | ดวงแบ่งย่อย โดยแบ่งแต่ละราศีเป็น 9 ส่วนและ 3 ส่วนตามลำดับ | `charts.navamsa`, `charts.drekkana` |
| ภพและเจ้าเรือน | ภพทั้ง 12 แบบนับตามราศี พร้อมเจ้าเรือนและดาวที่สถิต | `houses` |
| ตนุลัคน์และตนุเศษ | ดาวเจ้าเรือนลัคนา ตนุเศษ และดาวร่วมราศีลัคนา | `factors` |
| ฤกษ์และมาตรฐานดาว | นักษัตรทั้ง 27 บาทฤกษ์ ชื่อฤกษ์ทั้ง 9 และมาตรฐานดาว เช่น เกษตรบดี มหาอุจ และนิจ | ฟิลด์ใน `points` |
| ทักษา | ทักษาทั้งแปด เช่น บริวาร อายุ และกาลกิณี | `taksa` |
| วันจันทรคติไทย | ขึ้น/แรมกี่ค่ำ เดือนจันทรคติ และประเภทปี เช่น อธิกมาสหรืออธิกวาร | `calendar.thaiLunarDate` |
| ดาวจร | ตำแหน่งดาวจร ภพเทียบดวงกำเนิด และผลต่างสมผุส | `calculateHoroscopeTransits()` |

**ตนุลัคน์** คือดาวเจ้าเรือนราศีลัคนา ส่วน **ตนุเศษ** คือดาวที่คำนวณได้ตามสูตรตนุเศษ มีเครื่องหมาย `*` กำกับในผัง อีกค่าหนึ่งคือดาวที่อยู่ร่วมราศีกับลัคนา API แยกทั้งสามรายการไว้ให้เลือกใช้ในการอ่านดวง

## เริ่มใช้งาน

ติดตั้งแพ็กเกจ:

```bash
npm install thai-astrology
```

### หมายเหตุก่อนผูกดวง

- **วันและเวลา:** กรอกเวลาตามนาฬิกาท้องถิ่นของสถานที่เกิด ไม่ต้องแปลงเป็น UTC ก่อนส่ง เลือก `era: "BE"` สำหรับ พ.ศ. หรือ `"CE"` สำหรับ ค.ศ. ให้ตรงกับปีที่กรอก วันที่นำเข้าใช้ปฏิทินเกรกอเรียน
- **เวลาเกิด:** ใช้เวลาจากสูติบัตรหรือข้อมูลที่เชื่อถือได้ หากไม่ทราบเวลาแน่นอน ให้ระบุไว้ว่าเป็นเวลาประมาณ เพราะลัคนาและภพอาจเปลี่ยนตามเวลาเกิด
- **สถานที่เกิด:** การเลือกจังหวัดใช้พิกัดเมืองศูนย์กลางเป็นจุดอ้างอิง หากทราบสถานที่เกิดจริง ใช้ละติจูดและลองจิจูดของจุดนั้นผ่าน [ตัวเลือกอาทิตย์ขึ้นตามพิกัด](docs/api.md#เวลาอาทิตย์ขึ้นตามพิกัด)
- **เขตเวลา:** สำหรับต่างประเทศ ใช้ UTC ของวันเวลาเกิดที่รวม DST แล้ว [ตัวช่วยเลือกเมือง](docs/api.md#ค้นหาสถานที่ตามประเทศและหา-offset) หาให้ได้ตามวันที่ผ่าน IANA/Intl ของระบบ หากแก้พิกัดเอง ต้องระบุ `timeZone` ที่ตรวจสอบแล้วหรือ UTC ที่ถูกต้อง พิกัดเพียงอย่างเดียวไม่บอกเขตเวลา
- **วิธีที่ใช้จริง:** แนะนำ `auto` ซึ่งเป็นค่าเริ่มต้นสำหรับจังหวัดไทยใน ค.ศ. 1900–2100 หลังคำนวณ ตรวจ `horoscope.profile.referenceMode` และ `referenceFallback` หากมี เพื่อทราบว่าเลือกวิธีใด เมื่อเทียบผลกับแหล่งอื่น ให้ใช้วัน เวลา พิกัด กรอบเวลาดาว และวิธีลัคนาเดียวกัน

ลองผูกดวงตัวอย่าง: **15 กันยายน พ.ศ. 2567 เวลา 08:30 น. เชียงใหม่**

```ts
import { calculateThaiHoroscope } from "thai-astrology"

const horoscope = calculateThaiHoroscope({
  date: { year: 2567, era: "BE", month: 9, day: 15 },
  time: { hour: 8, minute: 30 },
  location: { province: "เชียงใหม่" },
})

console.log(horoscope.points.ascendant.signName) // กันย์
console.log(horoscope.points.sun.signName) // สิงห์
console.log(horoscope.calendar.thaiLunarDate?.label) // ข๑๓ด๑๐ = ขึ้น 13 ค่ำ เดือน 10
```

เปลี่ยนข้อมูลใน `date`, `time` และ `location.province` เพื่อผูกดวงอื่น ตัวอย่างนี้ใช้ `year: 2024, era: "CE"` แทน พ.ศ. ได้ เวลาเป็นตัวเลข ชั่วโมง 0–23 และนาที 0–59 ไม่ต้องใส่ชื่อหรือเพศ

**ตั้งค่าให้อัตโนมัติ:** เมื่อระบุจังหวัดไทยและวันเกิดอยู่ใน ค.ศ. 1900–2100 `calculateThaiHoroscope()` จะเติมพิกัดจังหวัด หา UTC ตามวันเวลาเกิด ใช้อาทิตย์ขึ้นรายวันแบบปัดนาที และเลือกกรอบเวลาดาว +06:42:04 ให้เอง ระบุเพียง `date`, `time` และ `location.province` ก็ใช้ได้ ไม่ต้องกรอกค่าคำนวณเหล่านี้เพิ่ม

หากใช้ CommonJS เปลี่ยนบรรทัด import เป็น `const { calculateThaiHoroscope } = require("thai-astrology")`

## นำข้อมูลไปแสดงราศีจักร

อ่านเลขดาวทั้ง 12 ช่องจาก `horoscope` แล้วนำไปวางในผังราศีจักรได้เลย:

```ts
console.log(horoscope.charts.rasi.channels.thai)
// ["", "๕*๐", "๓", "", "๑๔", "ลั๖", "", "", "๙", "๒", "๗", "๘"]
```

ช่องดวงเรียงจากเมษถึงมีน รวม 12 ช่อง ช่องที่ไม่มีดาวจะเป็นข้อความว่าง `ลั` หมายถึงลัคนา และ `*` กำกับตนุเศษ หากต้องการเลขอารบิก ใช้ `channels.arabic` หรือเปลี่ยน `rasi` เป็น `navamsa` และ `drekkana` เพื่ออ่านนวางค์จักรและตรียางค์จักร

คุณออกแบบหน้าตาผังดวงได้เอง โดยใช้ข้อมูลที่ไลบรารีคำนวณให้ หากต้องการสร้าง SVG ดู [สคริปต์ที่ใช้สร้างภาพด้านบน](scripts/render-readme-chart.cjs) เป็นตัวอย่างได้

หากต้องการแสดงตารางสมผุส ให้อ่านชื่อราศีและองศา/ลิปดาของแต่ละดาวจาก `points` ส่วน `longitudeDegrees` เป็นสมผุสองศารวม ใช้คำนวณมุมได้ เลขราศีใน API เริ่มที่ 0–11 และเลขภพเริ่มที่ 1–12 ดูหน่วยและรายละเอียดของแต่ละฟิลด์ในคู่มือ API

เมื่อต้องการแสดงวันตามปฏิทิน ใช้ `calendar.thaiLunarDate` ส่วน `calendar.lunarDay` เป็นดิถีจากมุมจันทร์กับอาทิตย์ จึงอาจต่างกัน ดวงตัวอย่างนี้ตรงกับขึ้น 13 ค่ำ เดือน 10 ส่วนดิถีจากมุมดาวเป็น 12

## หลักการและข้อจำกัด

ภาพประกอบด้านบนเป็นดวง 21 เมษายน พ.ศ. 2325 เวลา 06:54 น. กรุงเทพมหานคร ซึ่งอยู่นอกช่วงอาทิตย์ขึ้นที่รองรับ จึงเลือกฐานเวลา 06:00 พร้อมค่าแก้ลองจิจูด 18 นาที เป็นจุดอ้างอิงลัคนา 06:18 โดยระบุ `referenceMode: "traditional"` ในสคริปต์สร้างภาพ ดู [วิธีตั้งกรอบอ้างอิงขั้นสูง](docs/api.md#อาทิตย์ขึ้นและกรอบเวลาดาว)

สมผุสดาวคำนวณตามสูตรสุริยยาตร์ ลัคนาใช้อันโตนาทีสามัญ ส่วนภพนับตามราศี (whole-sign) โดยให้ราศีลัคนาเป็นภพที่ 1 มุมสัมพันธ์นับตามราศีเช่นกัน เมื่อนำผลไปอ่านดวงหรือเทียบกับต่างสำนัก ควรใช้หลักเดียวกัน

ค่าแก้จังหวัดในวิธี `traditional` คำนวณจากลองจิจูดเมืองศูนย์กลางในกรอบ UTC+7 แล้วปัดเป็นนาที ไม่ใช้ตารางค่าแก้นาทีคงที่ หากต้องการใช้พิกัดหรือ UTC ต่างจากกรอบนี้ ใช้ [ตัวช่วยคำนวณค่าแก้ตามพิกัด](docs/api.md#ค่าแก้เวลาสุริยะเฉลี่ยจากพิกัด) ได้ ส่วน `auto` ใช้อาทิตย์ขึ้นรายวันและ UTC ตามวันที่

การตั้งค่าอัตโนมัติทำงานเมื่อไม่ได้ระบุจุดอ้างอิงหรือค่าแก้จังหวัดเอง หากส่ง `ascendantReference` หรือ `planetaryTimeReference` มา จะใช้ตามที่ระบุ โดย UTC ของสถานที่เกิดกับกรอบคำนวณดาวยังเป็นคนละค่า ส่วน `calculateDetailedPositions()` และ API ผังดวงแบบเดิมยังคงค่าเริ่มต้นเดิม อ่านรายละเอียดใน [คู่มือ API](docs/api.md#อาทิตย์ขึ้นและกรอบเวลาดาว)

| ส่วนคำนวณ | แหล่งอ้างอิง |
| --- | --- |
| ปฏิทินและเลขคณิตจันทร์ | ตำราสุริยยาตร์ที่เผยแพร่ และงานศึกษาปฏิทินของ J. C. Eade |
| อาทิตย์ขึ้น | สูตรคำนวณอาทิตย์ของ NOAA/Meeus และนิยามอาทิตย์ขึ้น–ตกของ USNO |
| สถานที่และเวลา | พิกัดจาก GeoNames และกฎเขตเวลา IANA ผ่าน Intl ของ Node.js หรือเบราว์เซอร์ |

รายละเอียดตำรา งานวิจัย โค้ดโอเพนซอร์ส และข้อมูลเปิดอยู่ใน [SOURCES.md](SOURCES.md)

- **ต่างประเทศ:** ชื่อประเทศอย่างเดียวใช้หาพิกัดและ UTC ไม่ได้ ลัคนายังใช้อันโตนาทีสามัญชุดเดียวกับดวงในไทย
- **ขอบเขตสถานที่:** มี 1,945 จุดใน 243 ประเทศ/ดินแดน รวมจังหวัดไทย 77 จุด แต่ละจุดมีละติจูด ลองจิจูด และชื่อเขตเวลา รายการยังไม่ครอบคลุมทุกเมืองหรือทุกเขตเวลา และมี 7 ประเทศ/ดินแดนจากรายการประเทศทั้งหมด 250 รายการที่ยังไม่มีสถานที่ให้เลือก
- **ช่วงปี:** ตัวช่วยอาทิตย์ขึ้นและ UTC ใช้ได้กับ ค.ศ. 1900–2100 ส่วนวันจันทรคติรองรับ ค.ศ. 1582–2076 ถ้าอยู่นอกช่วงนี้ `thaiLunarDate` จะเป็น `null` วันที่จันทรคติที่คำนวณได้อาจต่างจากปฏิทินที่เผยแพร่
- **อาทิตย์ขึ้น:** คำนวณจากขอบฟ้าระดับทะเล โดยไม่ชดเชยภูเขา ความสูงของสถานที่ หรือสภาพอากาศ หากเลือกวิธีอาทิตย์ขึ้นในวันที่ไม่มีอาทิตย์ขึ้น ฟังก์ชันคำนวณดวงจะโยนข้อผิดพลาด `RangeError`

`calculateThaiHoroscope()` ใช้สุริยยาตร์เสมอ ส่วน API เดิม `generateThaiAstrologyChart()` ใช้ `legacy` เป็นค่าเริ่มต้น ต้องระบุ `method: "suriyayatra"` เมื่อต้องการสุริยยาตร์

## พัฒนาและร่วมปรับปรุง

[ชุดทดสอบ](test/run.cjs) ครอบคลุมกฎปฏิทิน รอยต่อราศี เขตเวลา และการเทียบผลกับเวอร์ชันที่เผยแพร่แล้ว นอกจากนี้ยังตรวจการใช้งานแพ็กเกจที่ติดตั้งจริงทั้ง CommonJS, ESM, TypeScript และเบราว์เซอร์ ดูขั้นตอนใน [CI workflow](.github/workflows/ci.yml)

ใช้ Node.js 24 สำหรับพัฒนา:

```bash
npm ci
npm run check
```

แก้โค้ดใน `src/` แล้วสร้างภาพตัวอย่างใหม่ได้ด้วย `npm run docs:chart` หากพบปัญหา แจ้งผ่าน [GitHub Issues](https://github.com/kongesque/thai-astrology/issues) พร้อมวัน เวลา สถานที่ และตัวเลือกคำนวณที่ใช้ โดยไม่ต้องใส่ชื่อหรือข้อมูลส่วนตัว
