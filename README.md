**`thai-astrology` คือไลบรารีโหราศาสตร์ไทยแบบโอเพนซอร์สสำหรับ JavaScript และ TypeScript** ใช้ผูกดวงกำเนิด คำนวณลัคนาและสมผุสดาวตามหลัก **สุริยยาตร์ (Suriyayatra)** พร้อมนวางค์จักร ตรียางค์จักร ทักษา วันจันทรคติไทย และดาวจร

สำหรับหมอดู ผลลัพธ์มีเลขดาว ชื่อราศี ภพ เจ้าเรือน และมาตรฐานดาวที่ใช้ในการอ่านดวง สำหรับนักพัฒนา ข้อมูลเดียวกันมีโครงสร้างพร้อมนำไปวาดผัง เขียนกฎแปลผล หรือให้บริการผ่าน API ส่วนคำพยากรณ์เป็นสิ่งที่แอปของคุณกำหนดเอง

รองรับ **Node.js 16+**, ESM, CommonJS และเบราว์เซอร์ผ่าน bundler โดยไม่มี runtime dependencies ผลดวงแปลงเป็น JSON ได้ ชื่อดาว ราศี ภพ และฤกษ์เป็นภาษาไทย

## คำนวณและอ่านอะไรได้บ้าง

| ผลทางโหราศาสตร์ | ข้อมูลที่ได้ | ฟิลด์ API |
| --- | --- | --- |
| ราศีจักร | ราศีของดาวทั้งสิบและลัคนา พร้อมช่องดวงเลขไทยหรืออารบิก | `charts.rasi` |
| สมผุสดาวและลัคนา | ราศี องศา/ลิปดา สมผุสรวม และภพของแต่ละจุด | `points` |
| นวางค์จักร / ตรียางค์จักร | ดวงแบ่งย่อยจากการแบ่งแต่ละราศีเป็น 9 และ 3 ส่วน | `charts.navamsa`, `charts.drekkana` |
| ภพและเจ้าเรือน | ภพทั้ง 12 แบบนับตามราศี พร้อมเจ้าเรือนและดาวที่สถิต | `houses` |
| ตนุลัคน์และตนุเศษ | ดาวเจ้าเรือนลัคนา ตนุเศษ และดาวร่วมราศีลัคนา | `factors` |
| ฤกษ์และมาตรฐานดาว | นักษัตร บาทฤกษ์ และป้ายมาตรฐานดาวที่รองรับ | ฟิลด์ใน `points` |
| ทักษา | แปดช่อง เช่น บริวาร อายุ และกาลกิณี | `taksa` |
| วันจันทรคติไทย | ขึ้น/แรมกี่ค่ำ เดือนจันทรคติ และประเภทปีอธิกมาส/อธิกวาร | `calendar.thaiLunarDate` |
| ดาวจร | ตำแหน่งดาวจร ภพเทียบดวงกำเนิด และผลต่างสมผุส | `calculateHoroscopeTransits()` |

**ตนุลัคน์** คือดาวเจ้าเรือนราศีลัคนา **ตนุเศษ** คือดาวที่ได้จากสูตรตนุเศษและกำกับด้วย `*` ในผัง ส่วนดาวร่วมราศีลัคนาคือดาวที่อยู่ในราศีเดียวกับลัคนา API แยกข้อมูลทั้งสามให้ใช้ตรงกับหลักแปลผลของคุณ

## เริ่มใช้งาน

ติดตั้งแพ็กเกจ:

```bash
npm install thai-astrology
```

ผูกดวงจากวันเกิด เวลาเกิด และจังหวัด:

```ts
import {
  calculateThaiHoroscope,
  createSunriseReference,
  resolveCivilTimeOffset,
} from "thai-astrology"

// แก้ข้อมูลเกิดตรงนี้ โดย yearCe ใช้ปี ค.ศ.
const birth = { yearCe: 2024, month: 9, day: 15, hour: 8, minute: 30 }
const province = "เชียงใหม่"

const { utcOffsetHours } = resolveCivilTimeOffset(birth, "Asia/Bangkok")
const horoscope = calculateThaiHoroscope({
  date: { year: birth.yearCe, era: "CE", month: birth.month, day: birth.day },
  time: { hour: birth.hour, minute: birth.minute },
  ascendantReference: createSunriseReference({
    province, utcOffsetHours, timePrecision: "minute",
  }),
  planetaryTimeReference: {
    civilUtcOffsetSeconds: Math.round(utcOffsetHours * 3600),
    referenceUtcOffsetSeconds: 6 * 3600 + 42 * 60 + 4,
  },
})

console.log(horoscope.points.ascendant.signName) // กันย์
console.log(horoscope.points.sun.signName) // สิงห์
console.log(horoscope.calendar.thaiLunarDate?.label) // ข๑๓ด๑๐ = ขึ้น 13 ค่ำ เดือน 10
```

กรอกข้อมูลเกิดที่ `birth` และเลือกจังหวัดที่ `province` โดย `yearCe` ใช้ปี ค.ศ. ถ้ามีปี พ.ศ. ให้ลบ 543 ชั่วโมงใช้ 0–23 และนาที 0–59 ตามนาฬิกาท้องถิ่น ไม่ต้องระบุชื่อหรือเพศ

โค้ดส่วนที่เหลือเป็นการตั้งค่าของแอป: หา UTC offset ตามวันที่ ใช้พิกัดจังหวัดคำนวณอาทิตย์ขึ้นรายวันแบบปัดนาที และคำนวณดาวในกรอบกรุงเทพฯ ประวัติศาสตร์ +06:42:04 ให้คงกรอบนี้ไว้เมื่อเปลี่ยนสถานที่ เพราะเป็นคนละค่ากับ UTC ของสถานที่เกิด ผู้ใช้ป้อนเพียงข้อมูลเกิด

สำหรับ CommonJS เปลี่ยน import เป็น `const { calculateThaiHoroscope, createSunriseReference, resolveCivilTimeOffset } = require("thai-astrology")`

อ่านวิธีใช้ [ต่างประเทศ พิกัดละเอียด และข้อมูลจากฟอร์ม](docs/api.md) ต่อในคู่มือ API หากต้องการคงวิธีอ้างอิง 06:00 พร้อมค่าแก้จังหวัด อ่าน [การตั้งค่า traditional](docs/api.md#วิธี-traditional)

## นำข้อมูลไปแสดงราศีจักร

ภาพหลักด้านบนเป็นดวงประวัติศาสตร์ที่อ้างอิงลัคนา 06:00 ส่วนโค้ดด้านบนเป็นอีกดวงในปี 2024 ที่ใช้อาทิตย์ขึ้นตามพิกัด อ่านช่องดวงนั้นจาก `horoscope`:

```ts
console.log(horoscope.charts.rasi.channels.thai)
// ["", "๕*๐", "๓", "", "๑๔", "ลั๖", "", "", "๙", "๒", "๗", "๘"]
```

ผลลัพธ์เป็นข้อความ 12 ช่อง เรียงจากเมษถึงมีน ช่องว่างหมายถึงไม่มีดาว `ลั` แทนลัคนา และ `*` กำกับตนุเศษ ใช้ `channels.arabic` หากต้องการเลขอารบิก หรือเปลี่ยน `rasi` เป็น `navamsa` / `drekkana` เพื่ออ่านนวางค์จักร / ตรียางค์จักร

ไลบรารีคืนข้อมูลสำหรับวาดผัง คุณเลือกหน้าตาและรูปแบบการแสดงผลเองได้ ดู [สคริปต์สร้างภาพตัวอย่าง](scripts/render-readme-chart.cjs) สำหรับการสร้าง SVG

แสดงสมผุสดาวจากชื่อราศีและองศา/ลิปดาภายในราศี หากต้องคำนวณมุม ใช้ `longitudeDegrees` ซึ่งเป็นองศารวม เลขราศีเริ่ม 0–11 ส่วนภพเริ่ม 1–12 คู่มือ API ระบุหน่วยและโครงสร้างผลลัพธ์ทั้งหมด

เมื่อต้องการแสดงวันตามปฏิทิน ใช้ `calendar.thaiLunarDate` ส่วน `calendar.lunarDay` เป็นดิถีจากมุมจันทร์กับอาทิตย์ จึงอาจต่างกัน ตัวอย่างนี้วันปฏิทินเป็นขึ้น 13 ค่ำ แต่ดิถีจากมุมดาวเป็น 12

## หลักการและข้อจำกัด

สมผุสดาวใช้สูตรสุริยยาตร์ ลัคนาใช้อันโตนาทีสามัญ และภพใช้ระบบนับตามราศี (whole-sign) มุมสัมพันธ์ก็นับตามราศี ข้อตกลงเหล่านี้มีผลเมื่อเทียบต่างสำนักหรือเขียนกฎพยากรณ์

ตัวอย่างเริ่มใช้งานเลือกอาทิตย์ขึ้นตามพิกัดแบบปัดนาที และกรอบเวลาดาวกรุงเทพฯ ประวัติศาสตร์ +06:42:04 อย่างชัดเจน กรอบนี้เป็นข้อตกลงการคำนวณ ส่วน UTC ของสถานที่เกิดหาแยกตามวันเวลา หากส่งเพียง `date`/`time`/`location` จะคงจุดอ้างอิง 06:00 พร้อมค่าแก้จังหวัดและเวลาดาว civil-local อ่านรายละเอียดใน [การตั้งค่าคำนวณ](docs/api.md#อาทิตย์ขึ้นและกรอบเวลาดาว)

| ส่วนคำนวณ | หลักฐานที่ใช้ประกอบ |
| --- | --- |
| ปฏิทินและเลขคณิตจันทร์ | คำอธิบายสุริยยาตร์ที่เผยแพร่ และงานปฏิทินของ J. C. Eade |
| อาทิตย์ขึ้น | สูตรอาทิตย์ NOAA/Meeus และนิยามอาทิตย์ขึ้น/ตกของ USNO |
| สถานที่และเวลา | พิกัด GeoNames และกฎเขตเวลา IANA ที่ runtime ใช้ |

[SOURCES.md](SOURCES.md) รวมตำรา งานวิจัย สูตรโอเพนซอร์ส ข้อมูลเปิด และสัญญาอนุญาต พร้อมขอบเขตของแต่ละแหล่ง แหล่งเหล่านี้อธิบายสูตรและแนวปฏิบัติ ไม่ได้รับรองผลคำนวณทุกตำแหน่ง

- **ข้อมูลเกิด:** ต้องมีเวลาเกิด เวลาสมมติหรือพิกัดเมืองศูนย์กลางจังหวัดอาจทำให้ลัคนาและภพเปลี่ยน หากทราบพิกัดจริง ให้ใช้พิกัดนั้น
- **ต่างประเทศ:** เลือกเมืองในรายการ หรือระบุละติจูด ลองจิจูด และ UTC ของวันเกิดที่รวม DST ประเทศอย่างเดียวไม่พอ ลัคนาต่างประเทศยังใช้อันโตนาทีสามัญชุดเดิม
- **ช่วงปี:** อาทิตย์ขึ้นและตัวช่วย UTC รองรับ ค.ศ. 1900–2100 วันจันทรคติรองรับ ค.ศ. 1582–2076 นอกช่วงคืน `null` และผลวันที่อาจต่างจากปฏิทินที่เผยแพร่
- **อาทิตย์ขึ้น:** ใช้ขอบฟ้าระดับทะเล ไม่ชดเชยภูเขา ความสูง หรืออากาศจริง วันที่ไม่มีอาทิตย์ขึ้นต้องจัดการแยก การผูกดวงด้วยตัวเลือกอาทิตย์ขึ้นในวันนั้นจะ throw `RangeError`

`calculateThaiHoroscope()` ใช้สุริยยาตร์เสมอ ส่วน API เดิม `generateThaiAstrologyChart()` ใช้ `legacy` เป็นค่าเริ่มต้น ต้องระบุ `method: "suriyayatra"` เมื่อต้องการสุริยยาตร์

## พัฒนาและร่วมปรับปรุง

[ชุดทดสอบสาธารณะ](test/run.cjs) ตรวจหลักปฏิทิน ขอบเขตราศี เขตเวลา และผลจากเวอร์ชันที่เผยแพร่แล้ว พร้อมตรวจแพ็กเกจที่ติดตั้งจริงทั้ง CommonJS, ESM, TypeScript และเบราว์เซอร์ ดูขั้นตอนใน [CI workflow](.github/workflows/ci.yml)

ใช้ Node.js 24 สำหรับพัฒนา:

```bash
npm ci
npm run check
```

แก้โค้ดใน `src/` และสร้างภาพตัวอย่างใหม่ด้วย `npm run docs:chart` หากพบปัญหา แจ้งผ่าน [GitHub Issues](https://github.com/kongesque/thai-astrology/issues) พร้อมวัน เวลา สถานที่ และวิธีคำนวณ โดยไม่ใส่ข้อมูลส่วนบุคคล
